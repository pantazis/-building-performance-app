Query parameter result states

Use these JSON-backed query parameters to preview the whole SRI14 page: Assessment summary, Domain cards, and SRI Results View table.

Default model ?nodata ?halfdata ?fulldata
?nodata No SRI result exists yet. The page turns to a missing-data state: score is 0%, class is N/A, domain cards are incomplete, and the results table shows unavailable cells.
?halfdata Only part of the assessment is complete. The page shows a provisional score/class, completed domains get scores, and missing domains/cells remain clearly marked.
?fulldata The SRI result is ready. The summary, gauge, domain cards, impact row, detailed matrix, and aggregated summary are populated for final review.
